# Аудит форм CeramicaDecor

Дата проверки: 2026-05-29.

Этот файл фиксирует формы в статическом дизайн-пакете и требования к их подключению во внутренней системе.

## Общие требования

Каждая публичная форма должна передавать:

- имя;
- телефон;
- комментарий, если поле есть в интерфейсе;
- страницу отправки;
- товар, изделие, артикул или формат обращения, если форма связана с конкретной сущностью;
- согласие на обработку персональных данных.

Для каждой формы должны быть предусмотрены:

- валидация обязательных полей;
- состояние отправки;
- состояние успешной отправки;
- состояние ошибки отправки;
- замена временного endpoint на обработчик внутренней системы.

Текущий endpoint `https://ceramicadecor.ru/feedback/ceramicadecor_pro` является временным.

## Что нужно унифицировать

- Все публичные формы должны иметь одинаковую структуру результата: loading, success, error.
- `fetch()` не должен игнорировать сетевые ошибки и ответ сервера.
- Все формы должны отправлять источник заявки: `location.href` или серверный route name.
- Формы, связанные с товаром или изразцом, должны отправлять ID/slug/артикул и ссылку на отдельную страницу карточки.
- Согласие на обработку персональных данных должно быть обязательным и проверяться не только HTML-атрибутом `required`, но и сервером.
- Временный endpoint должен быть заменен централизованным обработчиком внутренней системы.
- После интеграции нельзя оставлять заявки только как декоративный frontend-сценарий.

## Рекомендуемый payload для публичных форм

```text
name
phone
comment
source_url
form_type
product_id / product_slug
article
category_id / category_slug
company
cooperation_type
consent
```

Не все поля нужны каждой форме. Важно, чтобы backend принимал единый понятный payload и сохранял источник заявки.

## Вывод

Формы визуально присутствуют во всех нужных местах: главная, контакты, модальные окна, каталог и раздел изразцов. Для финальной интеграции нужно унифицировать обработчики, добавить явные error-состояния там, где их сейчас нет, и заменить временный endpoint на обработчик внутренней системы.
