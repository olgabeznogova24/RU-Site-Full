# Динамические зоны CeramicaDecor

Дата проверки: 2026-05-29, строка про выдачу карточек изразцов и раздел «Избранное» — 2026-07-29.

Этот файл фиксирует, какие данные в статической верстке являются демонстрационными и должны заменяться данными из внутренней системы при интеграции.

## Каталог

| Зона | Где сейчас в статике | Что должен подключить программист |
|---|---|---|
| Разделы каталога | шапка, футер, `catalog*.html`, `search.js` | реальные категории, их URL, порядок, SEO-названия и видимость |
| Активный раздел | `window.CATALOG_DEFAULT_CATEGORY` в файлах `catalog-*.html` | текущую категорию из маршрута/контроллера |
| Названия и описания разделов | `categoryTitles`, `categorySubtitles` в `catalog*.html` | данные категории из админки или справочника |
| Баннеры разделов | hero-блоки `catalog*.html` и изображения `banner-*` | баннер категории: desktop/mobile, alt, fallback |
| Список товаров | массив `products` внутри `catalog*.html` | реальные товары/работы из базы с учетом категории, фильтров и пагинации |
| Пустые разделы | текст `Это демонстрационный шаблон раздела...` | нормальное состояние пустой выдачи или реальные товары |
| URL карточек | демонстрационные `?product=...` и `?article=...` | полноценные URL отдельных страниц товара/изразца |

Важно: карточки товаров должны вести на отдельные страницы, а не открывать детальную карточку в модальном окне.

## Карточка товара или изделия

| Данные | Где сейчас в статике | Что заменить |
|---|---|---|
| Название, коллекция, краткое описание | поля `name`, `collection`, `desc` в `products` | поля товара из админки |
| Полное описание | `fullDesc` в `products` | SEO/маркетинговое описание товара |
| Цены | `price`, `priceTurnkey` в `products`, `PRODUCTS` в `search.js` | актуальные цены, статусы "от", "по запросу", валюта |
| Характеристики | `specs` в `products` | структурированные характеристики товара |
| Галерея | `images` в `products` и файлы `images/*` | реальные фото товара, порядок, alt, WebP/JPG |
| Видеоотзывы | `reviewMap` и VK ID в `catalog*.html` | связанные видео или отзывы из админки |
| Связанные товары | текущие демо-связки в модальных блоках | реальные рекомендации/похожие товары |
| 3D-модель облицовки | ссылка `.product-3d-link` с `data-product-3d-model` и `href="#"` в шаблонах камина и барбекю комплекса | ссылку на файл модели: адрес, формат, размер; если модели у товара нет — ссылку не выводить |

Детальная страница товара должна быть отдельным шаблоном с обычным URL. Текущие product/izrazcy modal-блоки можно использовать только как визуальный ориентир для состава данных, но не как основной сценарий открытия карточки.

## Карточки реализованных проектов на главной

Блок `showcase` в `index.html` содержит пять демонстрационных карточек проектов.

| Зона | Где сейчас в статике | Что должен подключить программист |
|---|---|---|
| Ссылка карточки | `product-*-template.html?product=<slug>` | URL реальной страницы товара/проекта |
| Артикул товара | `data-project-article` у кнопки заявки | артикул из внутренней системы |
| Название товара | `data-project-name` у кнопки заявки и текст `showcase__name` | название товара из внутренней системы |
| Цены | `showcase__price` в разметке | цены из внутренней системы, округленные до ближайшей 1000 рублей |

Отдельных HTML-файлов под каждый проект главной страницы нет и делать их не нужно. Ссылки ведут на подходящий шаблон карточки с демонстрационным параметром `?product=<slug>`:

| Карточка | Артикул | Текущая демонстрационная ссылка |
|---|---|---|
| Камин Альбион | 2882 | `product-drovyanoi-kamin-template.html` |
| Камин Версаль | 81 | `product-drovyanoi-kamin-template.html?product=kamin-versal` |
| Барбекю комплекс «Птички» | 3548 | `product-barbekyu-kompleks-albion-template.html?product=barbekyu-kompleks-ptichki` |
| Банный портал «Сувенир» | 5426 | `product-drovyanoi-kamin-template.html?product=bannyy-portal-suvenir` |
| Отопительно-варочная печь «Арт Нуво» | 3713 | `product-drovyanoi-kamin-template.html?product=otopitelno-varochnaya-pech-art-nuvo` |

## Изразцы

| Зона | Где сейчас в статике | Что должен подключить программист |
|---|---|---|
| База изразцов | `izrazcy-data.js` | реальные изразцы из внутренней системы |
| Связи и варианты | `izrazcy-relations.js` | реальные связи коллекций, вариантов, комплектов |
| 360-фото | `izrazcy-360-data.js` и `images/izrazcy-360` | реальные 360-изображения только там, где они нужны |
| Фильтры | сайдбар `catalog-filter-template` — статический макет: чекбоксы и поля кликаются, но на выдачу не влияют; в `script.js` есть только раскрытие панели (уточнено 2026-07-30) | серверные или клиентские фильтры по реальным полям |
| Пагинация | `PER_PAGE`, `renderPagination()` в `catalog-izrazcy.html` | пагинацию из backend или API |
| URL изразца | демонстрационный `?article=ARTICLE` | отдельную страницу изразца с постоянным URL |
| Выдача карточек | демонстрационная: на первой странице 24 карточки (1 реальная + 23 заглушки, фото только у первых трёх), страницы 2+ пустые | реальную выдачу изразцов на всех страницах |
| SEO-тексты раздела | текстовый блок из 4 разделов под каталогом в `catalog-izrazcy.html` (`.izrazcy-seo--bottom`) | редактируемые SEO-тексты из внутренней системы |

Файлы `izrazcy-data.js`, `izrazcy-relations.js` и `izrazcy-360-data.js` являются демонстрационной контентной базой, а не обязательной частью дизайна. Из папки `images/izrazcy-360` в дизайн-пакет входит только артикул `77133_52089_11647`, задействованный в демо-карточке и шаблоне `product-izrazec-template.html` (см. `readme.md`, раздел 14.10).

## Поиск

| Зона | Где сейчас в статике | Что заменить |
|---|---|---|
| Страницы сайта | `PAGES` в `search.js` | индексируемые страницы из маршрутов/CMS |
| Товары обычного каталога | `PRODUCTS` в `search.js` | реальные товары из базы |
| Изразцы | загрузка `window.izrazcyCatalog` в `search.js` | реальные изразцы из базы или поискового индекса |

Поиск сейчас является интерфейсной демо-реализацией. При интеграции источник результатов должен быть единым с реальным каталогом.

## Что важно передать программисту

- Статика показывает внешний вид и поведение шаблонов, но не является источником правды по товарам, ценам и остаткам.
- Все массивы товаров и изразцов в HTML/JS являются демонстрационными.
- Все URL карточек должны стать обычными ссылками на отдельные страницы.
- Header, footer, карточки, формы, контакты и SEO-блоки нужно вынести в переиспользуемые шаблоны/partials при интеграции.
