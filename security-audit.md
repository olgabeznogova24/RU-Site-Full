# Проверка перед публикацией в GitHub

Дата проверки: 2026-05-29.

## Что проверено

Проверены файлы проекта перед публикацией в репозиторий `olgabeznogova24/RU-Site-Full.git`.

## Результат

Явные приватные данные не найдены:

- `.env` и `.env.*` отсутствуют;
- приватные ключи SSH/SSL не найдены;
- сертификаты `.pem`, `.key`, `.p12`, `.pfx` не найдены;
- дампы базы `.sql`, `.sqlite`, `.sqlite3` не найдены;
- токены GitHub/OpenAI/Slack/AWS и похожие секреты не найдены;
- временные файлы `.tmp`, `.raw`, `.bak`, `.psd`, `.ai`, `.sketch`, `.fig` не найдены.

## Что есть в проекте

- Публичные телефоны, email, адреса и юридические данные в HTML-страницах.
- Публичные `canonical`, `og:url`, `robots.txt` и `sitemap.xml` для домена `https://ceramicadecor.ru/`.
- Временный endpoint форм `https://ceramicadecor.ru/feedback/ceramicadecor_pro`, который уже отмечен в аудитах как точка для замены при интеграции.
- Служебные страницы `login.html` и `password-recovery.html`; они являются статическими демо-шаблонами без реальных паролей.

## Что исключено через `.gitignore`

- `images/izrazcy-360/`;
- `.env` и похожие env-файлы;
- приватные ключи и сертификаты;
- дампы баз данных;
- временные, backup и исходные design-файлы;
- `node_modules/`, `vendor/`, `dist/`, `build/`.

## Вывод

Проект можно публиковать в GitHub как статический дизайн-пакет. Тяжелая папка `images/izrazcy-360/` исключена из git.
